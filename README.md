🌟 Overview

E-Bill Book is a modern billing solution designed to simplify invoice generation for Indian retailers. Create professional invoices within seconds, manage products and customers, export PDF bills, and instantly share them with customers through WhatsApp.

---

✨ Features

- 🧾 Professional Invoice Generation
- 📄 PDF Bill Export
- 💬 WhatsApp Bill Sharing
- 🛍️ Product Management
- 👤 Customer Management
- 🧮 Automatic Calculations
- 🇮🇳 GST-Friendly Billing
- 📱 Mobile-Responsive Design
- ☁️ Cloud-Based Access
- 🔒 Secure & Reliable

---

🚀 Getting Started

Prerequisites

- Node.js (Latest LTS Recommended)

Installation

npm install

Environment Variables

Create a ".env.local" file and add:

GEMINI_API_KEY=YOUR_GEMINI_API_KEY

Run Locally

npm run dev
